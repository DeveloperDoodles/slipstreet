# Sound credits

Every sound file in the game is in the **public domain (CC0)**, so it can be used anywhere,
including in a commercial game, with no conditions. Credit isn't required, but here it is anyway.

All recordings come from [Freesound](https://freesound.org). They were edited for the game: trimmed,
filtered, level-matched and looped. The engine recording was also pitch-tracked so it can be played
back at any rpm.

The engine is synthesised in code (a designed V8 voice), as are wind, road roar, turbo whistle and
flutter, wall scrape, street echo and the menu sounds.

PritzProductions (CC0) is still in `public/audio` for the optional recorded-engine layer
(`RECORDED_ENGINE` in `src/audio.js`).
